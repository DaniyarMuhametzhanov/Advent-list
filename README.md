# Вишлист-календарь

Сайт, где у каждого пользователя есть календарь желаний. В любой день можно положить
«желание» (картинка, название, комментарий) и для каждого друга отдельно решить,
видит ли он этот день.

## Структура

```
wishlist-calendar/
├── backend/    # сервер: Java 21 + Spring Boot 3
├── frontend/   # интерфейс: React + Vite + TypeScript
├── docs/       # заметки по этапам
├── .gitignore
└── README.md
```

## Что нужно установить

| Программа | Версия | Зачем |
|-----------|--------|-------|
| Git | любая свежая | история изменений кода |
| JDK (Temurin) | 21 | запуск Java-кода |
| Node.js | 20 LTS или новее | запуск и сборка фронтенда |
| Docker Desktop | свежая | PostgreSQL, Redis, MinIO в контейнерах |
| IntelliJ IDEA Community | свежая | редактор для Java |
| VS Code | свежая | редактор для фронтенда (по желанию) |

Maven отдельно ставить не нужно: в проекте будет Maven Wrapper (`mvnw`).
